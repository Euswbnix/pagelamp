**First release of PageLamp** — a local course knowledge base for the AI app you already use.
See the [README](https://github.com/Euswbnix/pagelamp#readme) for setup and the
[CHANGELOG](https://github.com/Euswbnix/pagelamp/blob/main/CHANGELOG.md) for what's included.

### Downloads
- **Desktop app** (includes the `pagelamp` command your AI app needs): `.dmg` for macOS
  (`aarch64` = Apple silicon, `x64` = Intel), `.msi` / `-setup.exe` for Windows,
  `.deb` / `.rpm` for Linux (they also install `/usr/bin/pagelamp`). The `.AppImage` runs the app,
  but your AI app can't use the `pagelamp` inside it in this release.
- **Command-line only:** `pagelamp-v0.1.0-<platform>.tar.gz` (`aarch64-apple-darwin` =
  Apple silicon Mac, `x86_64-apple-darwin` = Intel Mac, `x86_64-unknown-linux-gnu` = Linux) or
  `…-x86_64-pc-windows-msvc.zip` (Windows); each contains `pagelamp`, `LICENSE` and `README.md`.
- **Checksums:** `SHA256SUMS` covers every file — verify with `shasum -a 256 -c SHA256SUMS --ignore-missing`.

### First launch
- **macOS:** the app, the `.dmg` and the command-line `pagelamp` are signed with a Developer ID and
  notarized by Apple. Drag PageLamp from the `.dmg` into **Applications** and open it from there;
  macOS asks once whether to open an app downloaded from the internet. Be online for that first run.
- **Windows:** the installers, the app and `pagelamp.exe` are signed, so Windows shows a verified
  publisher. SmartScreen may still warn while this new release builds up reputation:
  **More info → Run anyway**.
- **Linux:** builds are not code-signed; check them against `SHA256SUMS`. Saving a calendar-feed link
  or Canvas token needs GNOME Keyring or KWallet.

### Known issues
- **Wrong week (for example "Week 22" in September):** Canvas can report a term much wider than the
  classes (the University of Toronto's Fall term runs from May to January). Set the real dates in the
  course's **Timeline** tab (*Wrong week? Set this course's term dates*).
- **Old courses keep syncing:** when an instructor never closed a past course in Canvas, it still
  appears. Hide it (course → *Settings* → *Hide this course*); it stays hidden and your AI app never
  sees it.
- Both are fixed properly in v0.3, which reads the syllabus and schedule to work out each course's
  week and lets you remove finished courses.

### Updating later
v0.1.0 doesn't update itself yet (automatic updates arrive in v0.3). After installing a newer
build, quit your AI app completely and open it again so it starts the new `pagelamp`.

### Please tell us
What worked, what didn't, and which week your courses are in vs. what PageLamp says —
[open an issue](https://github.com/Euswbnix/pagelamp/issues/new/choose) and add a diagnostic
report (*Settings → Help & feedback → Copy diagnostic report…*, or `pagelamp report`). Read it
first; never paste tokens, calendar links or course materials.
