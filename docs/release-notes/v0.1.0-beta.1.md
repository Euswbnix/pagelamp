**First public beta of Weekmark** — a local course knowledge base for the AI app you already use.
See the [README](https://github.com/Euswbnix/weekmark#readme) for setup and the
[CHANGELOG](https://github.com/Euswbnix/weekmark/blob/main/CHANGELOG.md) for what's included.

### Downloads
- **Desktop app** (includes the `weekmark` command your AI app needs): `.dmg` for macOS
  (`aarch64` = Apple silicon, `x64` = Intel), `.msi` / `-setup.exe` for Windows,
  `.AppImage` / `.deb` for Linux.
- **Command-line only:** `weekmark-<version>-<platform>.tar.gz` / `.zip`.
- **Checksums:** `SHA256SUMS` covers every file — verify with `shasum -a 256 -c SHA256SUMS --ignore-missing`.

### First launch (builds are not code-signed yet)
- **macOS:** open Weekmark once, then **System Settings → Privacy & Security → Open Anyway**.
  If that doesn't appear, or your AI app can't start Weekmark afterwards, run once:
  `xattr -dr com.apple.quarantine /Applications/Weekmark.app`
- **Windows:** SmartScreen → **More info → Run anyway**.
- **Linux:** saving a calendar-feed link or Canvas token needs GNOME Keyring or KWallet.
