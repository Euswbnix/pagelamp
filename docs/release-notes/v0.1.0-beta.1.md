**First public beta of StudentOS** — a local course knowledge base for the AI app you already use.
See the [README](https://github.com/Euswbnix/studentos#readme) for setup and the
[CHANGELOG](https://github.com/Euswbnix/studentos/blob/main/CHANGELOG.md) for what's included.

### Downloads
- **Desktop app** (includes the `studentos` command your AI app needs): `.dmg` for macOS
  (`aarch64` = Apple silicon, `x64` = Intel), `.msi` / `-setup.exe` for Windows,
  `.AppImage` / `.deb` for Linux.
- **Command-line only:** `studentos-<version>-<platform>.tar.gz` / `.zip` (+ `.sha256`).

### First launch (builds are not code-signed yet)
- **macOS:** right-click StudentOS.app → **Open** → **Open**. If your AI app can't start StudentOS
  afterwards, run once: `xattr -dr com.apple.quarantine /Applications/StudentOS.app`
- **Windows:** SmartScreen → **More info → Run anyway**.
- **Linux:** saving a calendar-feed link or Canvas token needs GNOME Keyring or KWallet.

### Please tell us

[open an issue](https://github.com/Euswbnix/studentos/issues/new/choose). Use made-up examples;
